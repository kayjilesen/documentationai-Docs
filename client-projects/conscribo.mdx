```bash

npm run lint           # ESLint + php -l
npm run lint:js:fix    # ESLint auto-fix
composer install && vendor/bin/phpcs
```

Husky: `lint-staged` + `npm run build` bij commit. De build-output (`style.css`, JS-bundle) staat in Git.

## Content seeder

**wp-admin → Hulpmiddelen → Content seeder**, per onderdeel aan te vinken. De onderdelen staan in `kj_seed_steps()`; `kj_seed_run( array $keys )` draait een selectie in vaste volgorde.

| Bestand | Inhoud |
|---------|--------|
| `scripts/seed-content.php` | Helpers, pagina's, CPT-content, runner |
| `scripts/seed-settings.php` | Media-import, menu's, thema-instellingen |
| `scripts/seed-ontwikkelingen.php` | Changelog-data |
| `scripts/seed-forms.php` | Gravity Forms (demo, contact, abonnement, afspraak, workshop) via GFAPI |
| `scripts/seed/pb-*.php` | Pagebuilder-inhoud per pagina |

```bash
wp eval 'require get_template_directory() . "/scripts/seed-content.php"; kj_seed_run( array( "nieuws" ) );'
```

<Callout kind="warning">
  Op staging wordt al content beheerd: draai daar alleen **losse pagina's** (`kj_seed_run( array(), array( 'samenwerkingen' ) )`). Een volledige run van "Pagebuilder-inhoud" overschrijft de pagebuilder van elke pagina.
</Callout>

<Expandable title="Formulieren in de seeder" default-open="false">
  - Formulieren worden op **titel** gezocht (ook inactieve) en bijgewerkt.
  - Pagebuilder-seeds halen de shortcode op via `kj_seed_form_shortcode( 'Titel' )`; nooit een formulier-id hardcoden.
  - Bij `GFAPI::update_form()` moet `is_active => '1'` in de array staan, anders wordt het formulier gedeactiveerd.
  - Een losse paginarun maakt een formulier alleen aan als het ontbreekt en overschrijft nooit een bestaand formulier.
  - Het demoformulier staat bewust op één pagina; "Abonnement aanvragen" is meertraps met voortgangsbalk (zonder percentage).
</Expandable>

<Expandable title="Nieuwe pagina toevoegen aan de seeder" default-open="false">
  1. Schrijf `kj_seed_pb_{naam}()` in een bestand onder `scripts/seed/`.
  2. Registreer hem in `kj_seed_pagebuilder_paginas()`.
  3. Met een `pagina`-sleutel (titel, samenvatting, menu_order) wordt de pagina zelf ook aangemaakt.
  4. Staat er een formulier op, zet de `kj_seed_form_*()`-functie onder `formulieren`.
</Expandable>

## Bijzonderheden

- Functieprefix `kj_`; text domain `conscribo`
- Pagebuilder: **nooit** velden direct in `group_pagebuilder.json` — altijd `group_layout_{slug}` + seamless clone
- Options: Thema instellingen (algemeen, topbar, header, footer, defaults, tracking)
- Header-dropdown klapt naar links als hij rechts buiten beeld valt
- Figma: "Design | Conscribo" (`9cYMwWTV4JSleA9XfrmQ2B`)
- Gedeelde clones: `group_button_fields`, `group_section_styling`
- ACF JSON: bij elke wijziging `modified` op een verse `date +%s`, nooit in de toekomst
- Klantdossier: `~/Dropbox/Projects/Conscribo/`
