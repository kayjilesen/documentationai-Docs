## Pagebuilder Blocks (14)

Elk blok staat in een eigen map in `templates/pagebuilder/` en wordt gerenderd via `loop.php`.

| Block | Beschrijving |
|-------|-------------|
| `hero` | Inhoud linksonder, gradient van linksonder naar rechtsboven (en bovenin voor het menu), pills met icoon, zwevende Werken bij-kaart vanaf `xl` |
| `text-image` | Tekst naast afbeelding |
| `cta` | Call-to-action |
| `cta-achtergrond` | CTA met achtergrondfoto, overlapt de sectie erboven; footer valt eroverheen |
| `cta-formulier` | CTA met SureForms-formulier |
| `diensten` | Diensten-grid |
| `projecten` | Swiper met liggende projectfoto's, gecentreerde watermerktitel, groene swiper-knoppen; kaarten optioneel zonder link |
| `over` | Over ons |
| `proces` | Werkwijze-stappen, kolomverdeling gelijk aan Voor wie |
| `cijfers` | Statistieken |
| `voor-wie` | Doelgroepkaarten in een raster van twee, icoon per kaart, geen rand of hover |
| `image` | Afbeelding |
| `logos` | Partner- en keurmerklogo's |
| `marquee` | Scrollende tekst, kleiner op mobiel |

<Callout kind="tip" title="Geen dubbele witruimte">
  Staan twee witte secties (`section.section-pd` zonder `bg-`-class) direct onder elkaar, dan vervalt de `padding-top` van de tweede. De regel staat in `assets/css/pagebuilder.css`.
</Callout>

## Werken bij-kaart

De vacaturekaart is een herbruikbare helper, `kj_werken_bij_card()` in `inc/helpers.php`. Hij staat in de hero en in de footer.

- Glasstijl: `bg-white/5` met `backdrop-blur`, tekst links, foto rechts, rond pijlknopje rechtsboven
- De link komt uit `kj_vacatures_link()`: de externe vacaturepagina van Hoex Group als die is ingevuld (opent in een nieuw tabblad), anders het `vacature`-archief
- Een goud bolletje toont het aantal open vacatures als dat groter is dan 0

| ACF-optie (Instellingen -- Algemeen) | Doel |
|---|---|
| `vacatures_url` | Externe vacaturepagina |
| `vacatures_label` | Linktekst (standaard "Werken bij") |
| `vacatures_aantal` | Aantal open vacatures voor het bolletje |
| `vacatures_kaart_titel` | Titel op de kaart |

```php
<?php kj_werken_bij_card( array(
    'titel'      => get_field( 'vacatures_kaart_titel', 'option' ),
    'subregel'   => 'Bekijk onze vacatures',
    'afbeelding' => $foto,
) ); ?>
```

## Header & Footer

- **Topbar** verdwijnt bij scrollen; de knop "Stuur een bericht" staat in de header
- **Actief menu-item** wit met een streep eronder, niet vet
- **Mobiel menu** compact
- **Footer**: titel over twee regels, kenmerken met logo of icoon, Werken bij-kaart, rustige juridische links
- **Formuliervelden** transparant met zwevende labels (JS in `script.js`)

## Build & Deploy

```bash
npm run dev          # Tailwind watch-modus
npm run build        # assets/css/style.css bouwen (geminificeerd)
npm run lint:js      # ESLint
```

<Callout kind="warning" title="Build vóór commit">
  Er draait geen build op de server. Deployer for Git haalt `main` op, inclusief de gebouwde `assets/css/style.css`. Draai dus altijd `npm run build` voordat je commit. De GitHub Actions CI/CD-workflow is bewust verwijderd.
</Callout>
