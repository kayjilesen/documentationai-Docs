## Overzicht

Lokale sites draaien op **`.local`** onder **`/DEV/<projectnaam>/`**. Het theme begint leeg en wordt gevuld vanuit [KJ-Boilerplate](/client-projects/kj-boilerplate).

## Kort pad

| Stap | Resultaat |
|------|-----------|
| MAMP PRO-host | `projectnaam.local` → document root `/DEV/projectnaam` |
| WordPress | Geïnstalleerd in die root |
| Themamap | `/DEV/projectnaam/wp-content/themes/projectnaam/` (eerst leeg, dan boilerplate) |
| Activeren + ACF Sync | Theme live lokaal; pagebuilder-JSON synct |

Geen `localhost:8888` als primaire URL.

## Claude-prompt (theme vullen)

Plak in Cursor (placeholders vervangen) — zelfde als in de theme-SOP:

```text
Zet een nieuw WordPress theme op op basis van kj-boilerplate.

Doelmap (leeg, handmatig aangemaakt):
/DEV/<projectnaam>/wp-content/themes/<projectnaam>

Bron:
/DEV/kj-boilerplate

Doe het volgende:
1. Kopieer de boilerplate-structuur naar de doelmap
2. Update style.css (Theme Name, Description, Text Domain) naar <projectnaam>
3. Pas text domain, prefixes en versieconstanten aan naar het project
4. Laat Tailwind/npm scripts intact
5. Geef een korte checklist: theme activeren, ACF Pro, ACF Sync
```

## npm (ondergeschikt)

Alleen nodig voor CSS/JS-build in de themamap:

```bash
cd /DEV/projectnaam/wp-content/themes/projectnaam
npm install
npm run dev    # tijdens UI-werk
npm run build  # voor commit/deploy
```

Detail: [KJ-Boilerplate](/client-projects/kj-boilerplate), [Tailwind Setup](/wordpress/tailwind-setup).

## Omgeving-detectie (optioneel)

`kj_is_live_domain()` in `inc/helpers.php` stuurt o.a. auto-updates. Lokaal (`*.local`) telt als niet-live. Productie-/staging-hosts projectspecifiek zetten wanneer die URL’s bekend zijn — niet blocking om te beginnen met bouwen.

## Troubleshooting

<Expandable title="Site niet bereikbaar op .local" default-open="false">
  MAMP-host aan? Servers gestart? Document root = `/DEV/projectnaam`? Zie [Omgeving (MAMP)](/sops/lokaal/omgeving).
</Expandable>

<Expandable title="ACF-velden verschijnen niet" default-open="false">
  **ACF → Sync** alle groepen met “Sync beschikbaar”. JSON moet in `acf-json/` van het actieve theme staan.
</Expandable>

<Expandable title="Tailwind classes ontbreken" default-open="false">
  `npm run dev` draaien; check `content`-paths in `tailwind.config.js` (o.a. `./templates/**/*.php`, `./inc/*.php`, `./*.php`).
</Expandable>
