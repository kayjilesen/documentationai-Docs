## Wat je op dag één moet kunnen

- Een lokale WordPress-site draaien op een `.local`-adres
- Het thema activeren en bij ACF op **Synchroniseren** klikken
- Een bestaand blok vinden in de map `templates/pagebuilder/` en zien hoe het op een pagina verschijnt
- De CSS bouwen met `npm run build`
- Een kleine wijziging in een eigen branch committen en pushen (laat Kay samenvoegen)
- Een docs-pagina aanpassen en uitzoeken waar hij verschijnt, zie [Getting Started FAQ](/help-center/faq/getting-started)
