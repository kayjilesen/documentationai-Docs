## Starten via Git

1. Clone de documentatie-repository lokaal
2. Open de repo in je editor
3. Maak of wijzig `.mdx` pagina's
4. Commit en push je wijzigingen naar Git

## Documenten bewerken

- Voeg een nieuw `.mdx` bestand toe of open een bestaande pagina
- Werk de content bij met Markdown en MDX-componenten
- Controleer of `documentation.json` de pagina in de juiste navigatiegroep bevat

## Publiceren

- Push naar de hoofdbranch om je wijzigingen live te zetten
