## Wat je nodig hebt

- Toegang tot het **projectbestand** (niet alleen een screenshot)  
- Pages: **Brand**, **Components**, **Design** — zie [Merk & Figma](/sops/design/merk-en-figma)  
- Desktop-artboards **1920** + grid 12×110 / gutter 40  

## Inspecteren

1. Selecteer een frame/laag  
2. Rechterpaneel: afmetingen, kleuren, fonts, gaps  
3. Noteer tokens → `tailwind.config.js`  

Dev Mode (als aan): handig voor CSS-achtige waarden — vertaal naar Tailwind-utilities, niet 1:1 plakken.

## Components vs instances

- **Components** (page Components): buttons, cards, header — bron  
- Op **Design**-pages: **instances** (kopieën die de bron volgen)  

Namen zoals `Section - FAQ`, `Card - Project` → pagebuilder-blokken. Zie [Naamgeving](/wordpress/naming-conventions) / design-SOP.

## Export

- Logo’s: SVG waar mogelijk  
- Iconen: SVG of sprite-afspraak in het theme  
- Foto’s: redelijke resolutie — zie [Images & media](/kennis/images-media)  

## Prototype (klant)

Niet de editor-link delen: **Present → Fit width → Share prototype → Anyone**. Zie [Review & handoff](/sops/design/review-en-handoff).

## Sneltoetsen (Mac)

| Handeling | Sneltoets |
|-----------|-----------|
| Selecteren en verplaatsen | `V` |
| Frame maken | `F` |
| Tekst maken | `T` |
| Rechthoek | `R` |
| Auto Layout toevoegen | `Shift + A` |
| Dupliceren | `Cmd + D` |
| Ongedaan maken / opnieuw | `Cmd + Z` / `Cmd + Shift + Z` |
| Alles in beeld | `Shift + 1` |
| Inzoomen op selectie | `Shift + 2` |
| Canvas verschuiven | Spatie ingedrukt houden en slepen |

Let op: terwijl je in een tekstlaag typt, typt een letter gewoon mee. Druk eerst op `Esc` voor je een sneltoets gebruikt.

## Meer uit de Figma-cursus

- **Kleuren als variabelen** met een naam die iets betekent (primair, tekst, achtergrond), nooit een losse kleurcode. Zo pas je een kleur op één plek aan en het sluit aan op de tokens in Tailwind.
- **Typeschaal met een vaste factor** (bijvoorbeeld 16 px, steeds × 1,25) en daarvan tekststijlen met lettertype, grootte, regelafstand en gewicht. Zo passen de groottes bij elkaar.
- **Components met meer dan één eigenschap**, bijvoorbeeld State (Default, Hover, Pressed) én met of zonder icoon in één set. Geef een icoon een naam met een slash (`icon/home`), dan kun je het in de knop wisselen.
- **Namen voor lagen**, geen `Rectangle 1`. Een component en een instance herken je aan het icoontje in het lagenpaneel.
- **Test het formaat:** maak een frame groter en kleiner om te zien of Auto Layout en constraints kloppen, vooral voor mobiel.
- **Prototype met Smart Animate:** kies een rustige curve, zet *Clip content* aan en groepeer vóór je begint. Koppel bij een slider de eerste en laatste slide.
- **Boolean operations** (Union, Subtract, Intersect, Exclude) voor eigen iconen. Laat de losse vormen bewerkbaar, zodat je het icoon later kunt aanpassen.
