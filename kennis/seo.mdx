## Wat SEO hier betekent

Techniek + inhoud zodat zoekmachines de site **begrijpen** en kunnen **tonen**. Geen “trucjes”, wel hygiëne.

## Basis-checklist

| Onderdeel | Richtlijn |
|-----------|-----------|
| **Title** | Uniek per pagina; merk + onderwerp |
| **Meta description** | Kort, uitnodigend (geen ranking-magic, wel CTR) |
| **Koppen** | Eén duidelijke H1; H2’s voor secties |
| **URL’s** | Kort, leesbaar (`/diensten/houtbouw`) |
| **Sitemap** | Via SEO-plugin (bij ons vaak **SureRank**) |
| **Canonical** | Voorkom dubbele URL’s (www vs non-www, staging) |
| **robots** | Live niet per ongeluk `noindex` |

Staging (`*.kayjilesen.dev`) mag noindex — live juist indexeerbaar.

## Content

- Unieke teksten; geen thin copy op 20 landings  
- Interne links tussen relevante pagina’s  
- Afbeeldingen: bestandsnaam + alt helpen marginaal  

## Af (begrip)

- [ ] Je weet wat title/H1/sitemap doen  
- [ ] Je checkt bij livegang geen staging-canonicals  
- [ ] Je snapt: SEO ≠ alleen een plugin aanzetten
