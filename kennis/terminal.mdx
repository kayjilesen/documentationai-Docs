## Basis

| Commando | Doel |
|----------|------|
| `pwd` | Waar ben ik? |
| `ls` | Bestanden in deze map |
| `cd mapnaam` | Ga naar map |
| `cd ..` | Eén map omhoog |
| `cd ~` | Home-map |
| `clear` | Scherm leeg |

Pad naar een theme (voorbeeld):

```bash
cd /DEV/projectnaam/wp-content/themes/projectnaam
```

## Git (kort)

```bash
git status
git pull
git add .
git commit -m "Bericht"
git push
```

Meer: [Git — basis](/kennis/git).

## npm (theme)

```bash
npm install      # eenmalig / na package-wijziging
npm run dev      # Tailwind watch
npm run build    # productie-build
```

## Handig

| Commando | Doel |
|----------|------|
| `code .` / `cursor .` | Map in editor openen (als CLI geïnstalleerd is) |
| `Cmd + C` | Lopende command stoppen (`npm run dev`) |

## Af (begrip)

- [ ] Je kunt naar de themamap `cd`-en  
- [ ] Je start `npm run dev` en stopt met Ctrl+C  
- [ ] Je runt basis-git zonder paniek
