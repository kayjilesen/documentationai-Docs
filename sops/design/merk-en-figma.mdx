## Doel

Een project-Figma dat 1:1 aansluit op hoe we bouwen: template-basis, vaste **pagina’s**, herbruikbare **components**, `Section -` / `Card -`-namen, desktop **1920** met grid **12 × 110 / gutter 40**.

## Start: template dupliceren

1. Open de KJ **Design-template** in Figma (team/files — niet vanaf een leeg bestand).  
2. **Duplicate** / kopieer naar het klantproject (juiste naam, bijv. projectnaam).  
3. Grid, 1920-artboards en basisstructuur blijven staan — pas daarna merk en UI aan.

<Callout kind="warning">
  Geen nieuw leeg Figma-bestand “from scratch” voor standaard WordPress-sites. Template = bron van waarheid voor canvas/grid.
</Callout>

## Pagina’s in het bestand

Houd (minimaal) deze Figma-**pages** aan:

| Page | Inhoud |
|------|--------|
| **Brand** | Logo’s, kleuren, fonts, eventueel fotostijl / tokens |
| **Components** | Buttons, header, footer, pills, cards, overige herbruikbare UI |
| **Design** | Pagina-artboards (Home, landings, …) opgebouwd uit component-instances |

Volgorde in de sidebar mag Brand → Components → Design (of zoals in de template). Niet alles op één page dumpen.

## Canvas & grid

(Al in de template; ter referentie / bij herstel:)

| Instelling | Standaard |
|------------|-----------|
| **Basis-artboard (desktop)** | **1920px** breed |
| **Kolommen** | **12** |
| **Kolombreedte** | **110px** |
| **Gutter** | **40px** |
| Mobiel / tablet | Eigen frames |

Contentbreedte = (12 × 110) + (11 × 40) = **1760px** → op 1920 **80px** margin L/R.

## Components

Op page **Components** — Figma components (geen losse kopieën op Design-pages):

| Type | Voorbeelden |
|------|-------------|
| **Chrome** | Header, Footer, navigatie |
| **UI** | Buttons (primary/secondary/ghost), pills/tags, inputs |
| **Cards** | Projectcard, teaser, USP, blogcard, … |
| **Overig** | Icon+tekst, terugkerende CTA-blokken |

Variants voor states waar nuttig. Op **Design** alleen **instances** — niet detachen tenzij bewuste uitzondering.

## Benaming

Patroon: **`Soort - Naam`** (spaties rond de streep, Title Case).

| Soort | Voorbeelden |
|-------|-------------|
| **Section - …** | `Section - FAQ`, `Section - Hero`, `Section - USP's` |
| **Card - …** | `Card - Project`, `Card - Team`, `Card - Review` |
| **Button - …** | `Button - Primary`, `Button - Secondary` |
| **Pill - …** | `Pill - Tag`, `Pill - Status` |
| **Header / Footer** | `Header`, `Footer` (of `Header - Main`) |

Namen = leidraad voor pagebuilder-blokken / PHP-components.

## Stappen

<Steps>
  <Step title="Template dupliceren" icon="copy">
    Design-template → duplicate naar projectbestand. Pages Brand / Components / Design intact laten.
  </Step>
  <Step title="Brand vullen" icon="palette">
    Logo, kleuren, fonts op page **Brand**. Styles/tokens voor Tailwind later.
  </Step>
  <Step title="Components projectspecifiek" icon="box">
    Op **Components**: merkkleuren/fonts doorvoeren; buttons, header, footer, pills, cards bijwerken of aanvullen.
  </Step>
  <Step title="Design-pagina’s bouwen" icon="figma">
    Op **Design**: artboards o.b.v. [FigJam-structuur](/sops/design/structuur-en-content). Secties als `Section - …`, cards als instances.
  </Step>
  <Step title="Mobiel + states" icon="smartphone">
    Kernpagina’s ook mobiel; lege states / lange content / hover waar relevant.
  </Step>
</Steps>
