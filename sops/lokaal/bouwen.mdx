## Doel

Site lokaal volgens handoff: secties als pagebuilder-blokken, herbruikbare components, realistische content — klaar voor eerste deploy naar `projectnaam.kayjilesen.dev`.

## Volgorde (aanbevolen)

<Steps>
  <Step title="Tokens / merk in theme" icon="droplet">
    Kleuren en fonts uit Figma **Brand** → `tailwind.config.js` + `@font-face` in `assets/css/input.css`. Zie [Tailwind Setup](/wordpress/tailwind-setup).
  </Step>
  <Step title="Header & footer" icon="layout">
    Markup in `header.php` / `footer.php` (+ helpers). Options via ACF waar de boilerplate dat al voorziet ([Options Pages](/acf/options-pages)).
  </Step>
  <Step title="Pagebuilder-blokken" icon="layers">
    Per Figma `Section - …` / `Card - …`:

    1. ACF layout-JSON (+ clone section styling, geen eigen padding-velden)  
    2. Map onder `templates/pagebuilder/<slug>/` (`*.php`, `*.css`, evt. `*.js`)  
    3. Registratie in pagebuilder flexible content  

    Naslag: [Pagebuilder](/acf/pagebuilder) (incl. link naar nieuw block), [Components](/acf/components).
  </Step>
  <Step title="PHP-components" icon="box">
    Buttons e.d. in `templates/components/` — gelijk houden aan Figma-components.
  </Step>
  <Step title="CPT’s" icon="database">
    Alleen wat in [FigJam](/sops/design/structuur-en-content) staat → `inc/post-types.php` (+ archief/single templates indien nodig).
  </Step>
  <Step title="Formulieren plaatsen" icon="mail">
    [SureForms](/wordpress/plugins/formulieren) op contact/CTA-pagina’s. Echte mailtest gebeurt op staging.
  </Step>
  <Step title="Content seeden" icon="file">
    Pagina’s met pagebuilder-slices; lengtes zoals in design. Geen productie-secrets.
  </Step>
  <Step title="Steekproef" icon="check-square">
    Desktop + mobiel op `.local`. ACF-JSON gecommit bij veldwijzigingen. CSS/JS: als styles niet meekomen → eenmalig `npm run dev` / `npm run build` in de themamap.
  </Step>
</Steps>

## Wat je níet lokaal hoeft “af” te hebben

- FluentSMTP / Pushover / SureCookie-productiepresets → [Staging — Stack](/sops/staging/stack-en-testen)
- DNS, `*.kayjilesen.dev` → Staging
- Domein-helper fine-tuning → wanneer staging-URL bekend is

## Af (per slice / vóór staging)

- [ ] Tokens/fonts uit Brand doorgevoerd (of ticket waarom later)
- [ ] Header/footer bruikbaar
- [ ] Afgesproken sections/cards van deze slice als blokken (+ ACF JSON in Git)
- [ ] CPT’s volgens FigJam (of n.v.t.)
- [ ] Formulieren op de juiste pagina’s
- [ ] Demo-content; desktop + mobiel OK op `.local`
- [ ] Geen secrets in de repo
