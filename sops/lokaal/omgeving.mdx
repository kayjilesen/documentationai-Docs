## Doel

Site bereikbaar op `projectnaam.local`, lege themamap klaar, tooling geïnstalleerd.

## Doe dit

Volg volledig: [Lokale ontwikkelomgeving](/devops/local-dev).

Kort:

1. WP op `.local` (geen `:8888` als primaire URL)  
2. Map `/DEV/<project>/wp-content/themes/<project>/`  
3. Node, Git, editor OK  
4. Daarna: [Theme / boilerplate](/sops/lokaal/theme-boilerplate)

## Af

- [ ] `https://projectnaam.local` (of http) bereikbaar
- [ ] Themamap bestaat met juiste projectnaam
- [ ] WP-admin bereikbaar; rechten OK om theme te activeren
- [ ] Node 18+ en Git beschikbaar
