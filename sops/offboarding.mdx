<Callout kind="info" title="Dit is een SOP">
  Alleen voor **Kay** (owner). Volgorde: **data veiligstellen → abonnementen/seats nalopen → toegang intrekken → secrets roteren**.
</Callout>

## Doel

1. Geen resttoegang tot systemen of klantprojecten  
2. **Data** die het bedrijf nodig heeft, blijft bereikbaar (niet gewist met het account)  
3. **Abonnementen / seats** die alleen voor die persoon golden, stopzetten of verlagen  

## Vooraf

- [ ] Offboard-datum en laatste werkdag bekend
- [ ] Welke **projecten** had deze persoon?
- [ ] Admin/owner ergens? (extra rotatie)
- [ ] Welke **betaalde seats/licenties** stonden op deze persoon? (Figma, Cursor, GitHub, Workspace, CRM, …)

---

## 0. Data bewaren (vóór je accounts sloopt)

Doe dit **eerste**, anders verdwijnt mail/Drive/Figma-drafts met de user.

| Bron | Bewaren / overdragen |
|------|----------------------|
| **Google Workspace** | Drive: eigendom van team-/projectmappen → Kay of shared drive. Mail: export (Takeout) of doorsturen + archive; beslissen bewaartermijn. Agenda: relevante agenda’s overzetten |
| **GitHub** | Open branches/PR’s mergen of overdragen; geen unieke WIP alleen lokaal laten zitten — push/archive vóór laatste dag |
| **Figma** | Drafts in personal drafts → verplaatsen naar team-/projectfile |
| **CRM** | Leads/deals waar user owner is → herverdelen; notities/export indien nodig |
| **Chat / tickets** | Belangrijke afspraken naar projectdossier of Pass-note |
| **Lokale machine** | Vragen: laatste push gedaan? Geen enige kopie van klantwerk alleen op die laptop |

### Af — Data

- [ ] Drive/mail/agenda afgehandeld (overdracht of bewuste export)
- [ ] Git: geen kritieke uncommitted/unmerged WIP meer alleen bij die persoon
- [ ] Figma-drafts in teamfiles
- [ ] CRM-owners herverdeeld
- [ ] Besluit vastgelegd: wat bewaren vs wissen (AVG: niet eeuwig bewaren “voor de zekerheid” zonder reden)

<Callout kind="tip">
  Workspace: eerst **transfer ownership** / shared drives, daarna pas user delete. Suspend kan tussendoor (login dicht, data nog veilig te migreren).
</Callout>

## 0b. Abonnementen & seats

Per tool: was er een **extra seat**, **named user**, of **persoonlijk abonnement** via de zaak?

| Type | Actie |
|------|--------|
| **Seat in teamplan** (Figma, GitHub, Cursor, Workspace, CRM, xCloud user, …) | Seat **verwijderen / niet verlengen** → factuur omlaag |
| **Persoonlijke Pro-licentie** op bedrijfs-card | Opzeggen of overzetten; bevestigingsmail bewaren |
| **Trial / duplicate tools** die alleen die persoon gebruikte | Opzeggen |
| **Domeinen / hosting** op hun naam | Zelden — check OpenProvider/Cloudflare contacten; eigendom moet bij Kay/bedrijf liggen |
| **WPMU DEV / agency seats** | Seat intrekken; plan downgraden als seat-count daalt |
| **Pushover / Maileroo extra user** | User weg → check of billing wijzigt |

### Af — Abonnementen

- [ ] Lijst seats/licenties van deze persoon nagelopen
- [ ] Opzeggingen / downgrades doorgevoerd of in kalender gezet (einddatum cycle)
- [ ] Geen doorlopende charge meer voor die seat (volgende factuur checken)
- [ ] Facturatiecontacten / receipts niet alleen in hun mail — bij Kay of boekhouding
