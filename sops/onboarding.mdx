## Doel

Nieuwe collega kan inloggen op alles wat de rol nodig heeft. Kay houdt bij *wat* er gedeeld is — dat is de input voor [Offboarding](/sops/offboarding).

## Toegangsoverzicht (mogelijk)

Niet iedereen krijgt alles. Vink aan wat je deelt; gebruik dezelfde lijst bij vertrek.

| Categorie | Systemen |
|-----------|----------|
| **Identiteit** | Google Workspace (`@kayjilesen.nl`), Proton Pass |
| **Code & docs** | GitHub (org + repo’s), docs / Documentation.ai |
| **Design** | Figma (team, Design-template, projectfiles) |
| **Lokaal** | MAMP PRO, Cursor, Git, Node (eigen machine) |

| **Mail-infra** | Maileroo, AWS/SES, PAX8 (M365), MXRoute — alleen indien rol |
| **Business** | **CRM** ([crm.kayjilesen.nl](https://crm.kayjilesen.nl)), evt. facturatie |
| **Alerts** | Pushover e.d. |

## Deel A — Teamlid / stagiaire

### Standaard pakket (meestal)

| Systeem | Waarvoor |
|---------|----------|
| **Google Workspace** | Mail `…@kayjilesen.nl`, Agenda, Drive |
| **Proton Pass** | Alle project- en tool-logins |
| **GitHub** | Theme-repo’s + documentatie |
| **Figma** | Design / FigJam |
| **Cursor** + **MAMP PRO** | Bouwen lokaal |
| **Deze kennisbank** | SOP’s + Documentatie |

### Op rol (vaak later / beperkt)

xCloud · Cloudflare · OpenProvider · WPMU DEV · CRM (`crm.kayjilesen.nl`) · Maileroo/SES/PAX8 · Pushover

### Stappen (teamlid)

<Steps>
  <Step title="Google Workspace" icon="mail">
    Account op **`@kayjilesen.nl`**. Inloggen, **MFA** aan, Agenda/Drive checken.
  </Step>
  <Step title="Proton Pass" icon="key">
    App + browser-extensie. Accepteer **gedeelde vault(s)**. Eigen Workspace-login in Pass zetten. Geen wachtwoorden via chat.
  </Step>
  <Step title="GitHub" icon="github">
    Account + **2FA**. Org/repo-uitnodiging. Clone toegewezen repo’s (themes + docs).
  </Step>
  <Step title="Figma" icon="figma">
    Team/bestanden; Design-template zichtbaar.
  </Step>
  <Step title="Lokale machine" icon="laptop">
    MAMP PRO, Git, Node, Cursor → [Lokaal — Omgeving](/sops/lokaal/omgeving).
  </Step>
  <Step title="Optioneel op rol" icon="sliders">
    Kay nodigt uit voor xCloud / Cloudflare / WPMU DEV / CRM ([crm.kayjilesen.nl](https://crm.kayjilesen.nl)) / … alleen als je die taken krijgt. Alles komt in Pass.
  </Step>
  <Step title="Docs + taak" icon="book">
    [Introductie](/introduction) → [SOP Overzicht](/sops/overzicht). Eén concrete eerste taak.
  </Step>
</Steps>

### Af — Teamlid

- [ ] Mail `@kayjilesen.nl` + MFA
- [ ] Proton Pass + gedeelde vault(s)
- [ ] GitHub + 2FA; kan clonen
- [ ] Figma OK
- [ ] MAMP + Cursor bruikbaar
- [ ] Extra tools (xCloud/CF/WPMU/CRM/…) alleen indien toegezegd + in Pass
- [ ] Intro + SOP Overzicht gelezen; eerste taak helder

### Wat je níet zelf doet (tenzij expliciet)

Domeinverhuizing / NS-cutover · productie `wp-config` / SMTP-keys zonder review · PAX8-partneracties · Cloudflare-zones voor klanten zonder afstemming · credentials in chat of Git

## Deel B — Kay (aannemen)

Noteer **per persoon** welke rijen uit het toegangsoverzicht je hebt gedeeld (Pass-note of interne checklist) → later [Offboarding](/sops/offboarding).

<Steps>
  <Step title="Workspace" icon="user-plus">
    User `naam@kayjilesen.nl` in Admin; groepen; MFA verplicht.
  </Step>
  <Step title="Proton Pass" icon="share">
    Juiste vault(s) — niet meer dan de rol nodig heeft.
  </Step>
  <Step title="GitHub + Figma" icon="github">
    Org/repo’s + Figma seat/project; Design-template.
  </Step>
  <Step title="Hosting / WP / business op rol" icon="server">
    Alleen indien nodig: **xCloud**, **Cloudflare**, **OpenProvider**, **WPMU DEV**, **CRM** ([crm.kayjilesen.nl](https://crm.kayjilesen.nl)), mail-tools. Pass-items klaarzetten.
  </Step>
  <Step title="Kick-off" icon="message-square">
    Eerste project + SOP-pad; kanaal voor vragen; review vóór productie-deploy. Noteer **welke seats** je aanzet (Figma, Cursor, …) — nodig bij [Offboarding](/sops/offboarding).
  </Step>
</Steps>

### Af — Kay (start)

- [ ] `…@kayjilesen.nl` + MFA
- [ ] Proton Pass vault(s)
- [ ] GitHub + Figma
- [ ] Optionele tools bewust gedeeld of bewust niet
- [ ] Lijst “wat heeft X?” + **welke betaalde seats** genoteerd (voor offboard)
- [ ] Eerste taak + docs gedeeld
