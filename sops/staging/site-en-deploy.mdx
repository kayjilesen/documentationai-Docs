<Callout kind="info" title="Dit is een SOP">
  Staging = **aparte xCloud-site** op de live-server, URL: **`projectnaam.kayjilesen.dev`**. DNS voor dat subdomein zet je in **Cloudflare** (zone `kayjilesen.dev`).
</Callout>

## Doel

Code draait op een deelbare URL via Git. Hosting-standaarden staan al goed (zelfde machine als later live).

## Stappen

<Steps>
  <Step title="Site aanmaken" icon="server">
    In xCloud op de **productieserver**: nieuwe WordPress-site, PHP 8.2+, label = projectnaam. Zie [Site Management](/hosting/site-management). Noteer het **server-IP** (nodig voor DNS).
  </Step>
  <Step title="DNS in Cloudflare" icon="cloud">
    In Cloudflare → zone **`kayjilesen.dev`** (bestaande zone; geen nieuwe site):

    - Type: **A** (of zoals xCloud voorschrijft)
    - Name: **`projectnaam`** (wordt `projectnaam.kayjilesen.dev`)
    - Value: IP van de xCloud-server
    - Proxy: **DNS only** (grijs) — zie ook [Cloudflare](/overig/cloudflare)

    Wacht tot de record resolve’t vóór je SSL forceert.
  </Step>
  <Step title="Domein & SSL in xCloud" icon="lock">
    Koppel **`projectnaam.kayjilesen.dev`** aan de site + Let's Encrypt. Zonder Cloudflare-record faalt cert/domein.
  </Step>
  <Step title="Git / Deployer" icon="git-branch">
    Koppel repo; deploy theme met [Deployer for Git](/hosting/deployments). Eerste push vanaf gebouwde slice.
  </Step>
  <Step title="Hosting-standaarden" icon="zap">
    Zet meteen de productiestandaard (blijft gelden na omzetting):

    - [Caching](/hosting/caching) — FastCGI 60 min + Redis  
    - [Backups](/hosting/backups) — remote incremental  
    - [Security](/hosting/security) — WAF  
  </Step>
  <Step title="ACF Sync + cache" icon="refresh-cw">
    Na deploy met JSON-wijzigingen: **ACF > Sync**. Purge page cache + Redis.
  </Step>
  <Step title="Domein-helper" icon="globe">
    Dit `*.kayjilesen.dev`-host opnemen in `kj_is_live_domain()` / project-equivalent (optioneel vroeg).
  </Step>
</Steps>

## Af

- [ ] xCloud-site aangemaakt; server-IP bekend
- [ ] Cloudflare A-record voor `projectnaam.kayjilesen.dev` (**DNS only** / grijs) gezet en resolve’t
- [ ] Domein + SSL in xCloud OK → `https://projectnaam.kayjilesen.dev` bereikbaar
- [ ] Theme/code via Git-deploy
- [ ] Caching + Redis volgens standaard
- [ ] WAF + remote backups aan
- [ ] ACF Sync gedaan indien nodig; caches gepurged
