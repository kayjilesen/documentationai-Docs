| Instelling | Waarde |
|------------|--------|
| Auto compress | Aan (Super / lossy) |

| Large image resize | Aan — max **1920 × 1920** |
| Original images | Aan |
| Backup originals | Uit |
| PNG → JPEG | Aan |
| Lazy load | Aan (jpeg/png/webp/gif/svg + iframes) |
| Missing image dimensions | Aan |
| Preload critical images | Aan |
| Next-gen | **AVIF** (direct conversion + fallback) |
| WebP module | Uit (AVIF i.p.v. WebP) |
| CDN | Uit |
| Keep data on uninstall | Aan |

Lazy load post types in de export o.a.: frontpage, home, page, single, archive, category, tag, plus project-CPT's waar aanwezig.
