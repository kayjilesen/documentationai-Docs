---
title: "WP Switchboard Pro"
description: "Standaard Switchboard-modules voor admin-cleanup, bloat removal en kleine security/performance-opties."
---

Standaardmodules voor alle sites (pagebuilder-stack). Afgeleid van overlap tussen recente productiesites, zonder dubbele security ten opzichte van [WP Defender](/wordpress/plugins/wp-defender).

Export: `wordpress/configs/wpswitchboard.json`

## Altijd aan

| Module | Doel |
|--------|------|
| `move-switchboard-to-tools` | Switchboard onder Tools i.p.v. top-level menu |
| `site-identity-login` | Login-scherm met site-branding |
| `disable-comments` | Comments uit |
| `duplicate-post-button` | Posts/pages dupliceren |
| `disable-dashicons-frontend` | Dashicons niet laden op front-end |
| `disable-emoji` | WP emoji-scripts uit |
| `disable-embeds` | oEmbed-scripts uit |
| `disable-feeds` | Feeds uit |
| `disable-self-pingbacks` | Self-pingbacks uit |
| `disable-gutenberg` | Block editor uit (ACF pagebuilder-sites) |
| `disable-admin-bar-frontend` | Geen admin bar op de front-end |
| `transients-cleaner` | Verlopen transients opruimen |
| `heartbeat-control` | Admin-heartbeat beperken |
| `disable-author-archives` | Author archives uit |
| `disable-file-editing` | Theme/plugin editor in admin uit |
| `disable-xmlrpc` | XML-RPC uit |
| `hide-wp-version` | WP-versie verbergen |
| `hide-login-errors` | Generieke login-foutmeldingen |
| `last-login-column` | Laatste login in users-lijst |
| `revisions-control` | Revisielimiet (**5**) |
| `clean-admin-bar` | Admin bar opschonen (zie settings) |
| `active-plugins-first` | Actieve plugins bovenaan |
| `disable-dashboard-widgets-select` | Standaard dashboard widgets verbergen |

## Module-settings (standaard)

**clean-admin-bar** — verberg: updates, comments, new content, howdy, help tab, screen options. Laat staan: WP logo, site name, customize.

**disable-dashboard-widgets-select** — o.a. Right Now, Activity, Quick Press, Primary, Welcome, Recent Comments/Drafts, Secondary.

**revisions-control** — limit: `5`

**disable-gutenberg** — mode `specific` voor pages + custom CPT's (projectafhankelijk welke post types).

## Optioneel per project

| Module | Wanneer |
|--------|---------|
| `svg-support` | SVG-uploads toestaan |
| `media-categories` | Media organiseren in categorieën |
| `remove-shortlink` / `remove-rss-feed-links` | Extra head-cleanup |
| `quick-debug-toggle` | Alleen op lokale/dev omgevingen |
| `download-plugin-zip` | Handig voor development, niet standaard op live |
| `username-blacklist` | Liever via [Defender](/wordpress/plugins/wp-defender) |
| `security-headers` | Liever via Defender (voorkom dubbele headers) |
| `disable-rest-api` | Alleen als je zeker weet dat REST niet nodig is (ACF/apps) |
| `obfuscate-author-slugs` | Extra enum-bescherming; Defender doet user-enum al |

## Niet als standaard (overlap andere tools)

- Performance: `defer-javascript`, `lazy-load-control`, `lcp-image-priority`, `add-missing-image-dimensions` — zit in [Hummingbird](/wordpress/plugins/hummingbird) / [Smush](/wordpress/plugins/smush)
- Login-lockouts / 2FA-achtige hardening — zit in Defender
