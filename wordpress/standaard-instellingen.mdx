## Overzicht

Elke nieuwe productiesite krijgt dezelfde WordPress-basis: vaste pluginpresets + dezelfde xCloud caching/backup-defaults. Config-exports staan in `wordpress/configs/`.

Dit staat onder **WordPress Development** (stack & plugins). Server, DNS en SSL blijven onder [Hosting](/hosting/server-setup).

| Onderdeel | Bron / export |
|-----------|----------------|
| **WP Defender** | `wordpress/configs/wp-defender.json` |
| **Smush Pro** | `wordpress/configs/smush.json` |
| **Hummingbird** (Asset Optimization) | `wordpress/configs/hummingbird-asset-optimization.json` |
| **WP Switchboard Pro** | `wordpress/configs/wpswitchboard.json` |

<Callout kind="info" title="Login-URL">
  Op productie is de WordPress-login altijd **`/beheer`** (niet `/wp-admin`). Dit wordt gezet via Defender → Mask Login Area.
</Callout>

## xCloud standaard

Checklist bij elke nieuwe site (details in [Server Setup](/hosting/server-setup), [Site Management](/hosting/site-management) en [Backups & Security](/hosting/backups-security)):

| Instelling | Standaard |
|------------|-----------|
| Provider | Hetzner via xCloud |
| Webserver | NGINX |
| PHP | Actuele stabiele 8.x |
| Database | MySQL 8 / MariaDB |
| Page cache | FastCGI Nginx, 60 minuten |
| Object cache | Redis Object Cache aan |
| Object Cache Pro | Uit |
| Cloudflare Edge Cache | Uit |
| SSL | Let's Encrypt + HTTPS aan |
| Firewall | UFW (22 / 80 / 443) |
| WAF | 8G (of 7G) actief op site-niveau |
| Backups | Remote Incremental (zie hieronder) |
| Staging | Optioneel per site |
| Deploy | Meestal [Deployer for Git](/hosting/deployments) of xCloud Git |

### Caching (Site > Caching)

| Module | Standaard |
|--------|-----------|
| **Page Caching** | Aan — methode **FastCGI Nginx**, cache duration **60 Minutes** |
| **Redis Object Cache** | Aan (credentials komen van xCloud per site) |
| **Object Cache Pro** | Uit |
| **Cloudflare Edge Cache** | Uit |

xCloud serveert gecachte pagina's via NGINX (buiten PHP/WordPress) en zet browser-cache headers op CSS, JS en images.

<Callout kind="tip">
  Na deploys of ACF/theme-wijzigingen: **Purge Cache** voor page cache én Redis object cache.
</Callout>

### Remote Backup (Site > Backups > Remote Backup)

| Instelling | Standaard |
|------------|-----------|
| Backup type | **Incremental** |
| Bucket | **xcloud** |
| Automatic Full Backup | Aan — **Weekly** |
| Backup Retention | Aan — **Delete After Days: 30** |
| Automatic Incremental Backup | Aan — **Daily** |
| Database Backup | Aan (**Take Database Backup**) |
| File Backup | Aan (**Take File Backup**) |

**Exclude Paths** (file backup):

```text
wp-admin
wp-includes
wp-content/plugins
wp-content/uploads
```

Core, plugins en uploads zitten dus niet in de file-backup (die herstel je via WordPress/plugins of media); database + overige sitebestanden (o.a. theme) wel. Uploads/media apart borgen waar nodig (bijv. WPvivid of object storage).

## Standaard plugin-stack

Typische WPMU DEV / performance / security-set op productie (exacte set kan per project verschillen):

| Plugin | Rol |
|--------|-----|
| **WP Defender** | Security, login mask (`/beheer`), lockouts, scans |
| **WP Switchboard Pro** | Admin-cleanup, bloat removal, kleine security/perf modules |

| **Hummingbird** | Asset optimization (minify/combine/delay JS) |

| **Nginx Helper** | Cache purge bij NGINX |
| Overig per project | ACF Pro, Rank Math, FluentSMTP, WPvivid, enz. |

## Hummingbird — Asset Optimization

Export dekt **Asset Optimization** (niet per se alle Hummingbird-modules).

| Instelling | Waarde |
|------------|--------|
| Minify | Aan |
| Mode | **Speedy** |
| Compress | Aan |
| Combine | Aan |
| Assets | Styles + scripts + fonts |
| Delay JS | Aan (timeout 20s) |
| Critical CSS | Uit |
| Font optimization | Uit (`font-display: swap` wel aan) |
| CDN | Uit |
| View | Basic |

**Niet minifien / niet combinen (o.a.):** `jquery`, `wphb-global`, plus diverse `wp-block-*` / global styles.

Delay JS heeft een lange standaard exclusion-lijst (lazy load, forms, trackers, theme-scripts). Importeer de JSON bij twijfel i.p.v. handmatig na te bouwen.

Export: [`wordpress/configs/hummingbird-asset-optimization.json`](/wordpress/configs/hummingbird-asset-optimization.json)

<Callout kind="tip">
  Na theme-deploy: clear Hummingbird/NGINX/Redis cache en test formulieren + pagebuilder-JS. Bij layout-breaks: delay/minify uitzonderingen uitbreiden.
</Callout>

## WP Switchboard Pro

Standaardmodules gebaseerd op recente productiesites (o.a. Hoexsystems). Activeer deze modules in Switchboard; details + settings staan in de export.

### Altijd aan

| Module | Doel |
|--------|------|
| `move-switchboard-to-tools` | Switchboard onder Tools i.p.v. top-level menu |
| `site-identity-login` | Login-scherm met site-branding |
| `disable-comments` | Comments uit |
| `duplicate-post-button` | Posts/pages dupliceren |
| `disable-dashicons-frontend` | Dashicons niet laden op front-end |
| `disable-emoji` | WP emoji-scripts uit |
| `disable-feeds` | Feeds uit |
| `transients-cleaner` | Verlopen transients opruimen |
| `disable-author-archives` | Author archives uit |
| `disable-file-editing` | Theme/plugin editor in admin uit |
| `disable-xmlrpc` | XML-RPC uit |
| `hide-wp-version` | WP-versie verbergen |
| `last-login-column` | Laatste login in users-lijst |
| `revisions-control` | Revisielimiet (**5**) |
| `clean-admin-bar` | Admin bar opschonen (zie settings) |
| `active-plugins-first` | Actieve plugins bovenaan |
| `disable-dashboard-widgets-select` | Standaard dashboard widgets verbergen |
| `download-plugin-zip` | Plugin als zip downloaden |
| `quick-debug-toggle` | Snelle debug-toggle |
| `security-headers` | Extra security headers |

### Module-settings (standaard)

**clean-admin-bar** — verberg: updates, comments, new content, howdy, help tab, screen options. Laat staan: WP logo, site name, customize.

**disable-dashboard-widgets-select** — o.a. Right Now, Activity, Quick Press, Primary, Welcome, Recent Comments/Drafts, Secondary.

**revisions-control** — limit: `5`

### Optioneel per project

| Module | Wanneer |
|--------|---------|
| `disable-gutenberg` | Classic editor / pagebuilder-sites (vaak pages + custom CPT's) |
| `disable-embeds` | Geen oEmbeds nodig |
| `svg-support` | SVG-uploads toestaan |
| `media-categories` | Media organiseren in categorieën |
| `heartbeat-control` | Admin-heartbeat beperken |
| `username-blacklist` | Extra naast Defender |
| `disable-admin-bar-frontend` | Geen admin bar op de front-end |

Export: [`wordpress/configs/wpswitchboard.json`](/wordpress/configs/wpswitchboard.json)

<Callout kind="warning">
  Licentiekeys horen niet in de docs of in Git. Activeer Switchboard Pro per site via je eigen licentie.
</Callout>

## Nieuwe site checklist

<Steps>
  <Step title="xCloud site klaarzetten" icon="server">
    PHP, SSL, WAF, **FastCGI Nginx + Redis**, en **remote incremental backups** volgens de xCloud-sectie hierboven.
  </Step>
  <Step title="Plugins installeren" icon="package">
    Defender, Switchboard Pro, Smush Pro, Hummingbird (+ overige projectplugins).
  </Step>
  <Step title="Configs importeren" icon="download">
    Importeer de JSON-presets uit `wordpress/configs/` (Defender/Smush/Hummingbird via Hub of import; Switchboard-modules volgens `wpswitchboard.json`).
  </Step>
  <Step title="Login controleren" icon="log-in">
    Bevestig dat `https://domein.nl/beheer` werkt en `/wp-login.php` gemaskeerd is.
  </Step>
  <Step title="Performance check" icon="zap">
    Smush bulk/lazy load oké; Hummingbird AO aan; caches legen; homepage + formulieren testen.
  </Step>
</Steps>
